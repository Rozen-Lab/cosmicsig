## Helpers

- [`SBS96_ID_to_SBS192_ID()`](https://rozen-lab.github.io/cosmicsig/reference/SBS96_ID_to_SBS192_ID.md)
  : Translate SBS96 signature IDs to SBS192 signature IDs by adding "-E"
  if necessary
- [`possible_artifacts()`](https://rozen-lab.github.io/cosmicsig/reference/possible_artifacts.md)
  : Return a character vector of the names of possible signature
  artifacts
- [`rare_signatures()`](https://rozen-lab.github.io/cosmicsig/reference/rare_signatures.md)
  : Return a character vector of the names of rare SBS96 signatures

## Deprecated

These are no longer maintained and may be incomplete for recent COSMIC
releases. For authoritative, up-to-date etiologies consult
<https://cancer.sanger.ac.uk/signatures/> directly.

- [`etiology`](https://rozen-lab.github.io/cosmicsig/reference/etiology.md)
  : List of mutational signatures' proposed etiology summarized from
  COSMIC, Catalogue Of Somatic Mutations In Cancer (v3.5 - November
  2025)
- [`get_etiology()`](https://rozen-lab.github.io/cosmicsig/reference/get_etiology.md)
  : Get the proposed etiology of mutational signatures.
